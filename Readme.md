# Serotonin Modulates Up-Down States in Anaesthetised Mice 

In this project, we implemented a firing rate model to uncover the mechanisms of this
serotonergic modulation during anaesthesia. The model simulates a network of brain regions as well as the
stimulation of serotonergic neurons in the DRN. Each region comprises one excitatory and
one inhibitory population of neurons which successfully reproduce the UP and DOWN
state dynamics.
